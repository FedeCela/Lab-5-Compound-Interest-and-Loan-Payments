# Lab-5-Compound-Interest-and-Loan-Payments

## Program 1: Compound Interest

My program asks the user to enter the principal balance follow ny the annual interest rate and number of times interest is compounded per year.

The program divides the interest rate by 100 to convert it into decimal form. Then, it uses the `pow` function to calculate the final savings amount.

The program calculates the interest earned by subtracting the principal from the final amount.

The results displayed are the interest rate, number of compounding periods, principal, interest earned, and final amount in savings.
